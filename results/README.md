# results/

Machine-readable experiment outputs, one folder per experiment (`results/EXP-NNN/`), written by the experiment runner with a versioned JSON schema and a run manifest, plus the frozen-rule analysis (`analysis/`), provenance table and SHA-256 manifest.

- `EXP-001/` to `EXP-004/`: confirmatory runs of 2026-11-24 (revision `d997cf8`). In `EXP-004/`, `results.json` and `metrics.csv` are git-ignored (D-012) and regenerated by `scripts/m3_run.sh EXP-004`.
- `exploratory/`: exploratory runs, never used for a confirmatory verdict. `smoke/`, `probe-*` (before the freeze), `m3-smoke/` (M3), `m4-analytic/` and `m4-cw-delta/` (M4, after all verdicts; J-0015, J-0016).
- `audit/`: M4 evidence-audit outputs (J-0017).
