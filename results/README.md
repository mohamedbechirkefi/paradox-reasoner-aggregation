# results/

Machine-readable experiment outputs, one folder per experiment (`results/EXP-NNN/`), written by the experiment runner with a versioned JSON schema and a run manifest. Large raw outputs go to `results/raw/` (ignored by git) and are regenerated by script. Empty at M0: no experiment has run.
